# 受控标签词表

规则：卡片只能使用下列标签；需要新标签时先在此追加定义（一次最多 3 个）。

## 学科 / 领域

| 标签 | 定义 |
| --- | --- |
| `语文` | 语文科相关：教材、文言文、阅读、作文 |
| `数学` | 数学科相关 |
| `英语` | 英语科相关 |
| `物理` | 物理科相关 |
| `化学` | 化学科相关 |
| `生物` | 生物科相关 |
| `政治` | 政治科相关 |
| `历史` | 历史科相关 |
| `地理` | 地理科相关 |

## 文档类型

| 标签 | 定义 |
| --- | --- |
| `教材` | 教科书、课本 |
| `试卷` | 考试卷、真题、模拟卷 |
| `讲评` | 试题讲评、答题要点、查漏补缺 |
| `作文` | 作文题、范文、作文分析、素材 |
| `文言文` | 文言文篇目、实词虚词、文学常识 |
| `阅读` | 整本书阅读、名著导读 |
| `通知` | 校方通知、告家长书 |
| `班务` | 班级事务：收支、名单、活动 |
| `研究报告` | 研究性学习报告、调查分析 |
| `数据` | 表格数据类（xlsx/csv） |
| `演示` | 幻灯片类（pptx） |
| `对话` | 由 AI 对话记录转换而来的原文层（`chats/`） |

## 用途 / 状态

| 标签 | 定义 |
| --- | --- |
| `范文` | 可作为写作范例的文章 |
| `素材` | 可直接引用的论据、事例、名言 |
| `模板` | 可复用的结构或格式 |
| `待分类` | 尚未确定归属 |
